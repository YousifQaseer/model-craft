# For coding agents

This repository is an agent skill. When asked to build a website around an
interactive 3D model of what the visitor is choosing (a restaurant's tables, a
hotel's rooms, a car configurator, "like the dollhouse"), read and follow
`skills/model-craft/SKILL.md`. Its `references/` folder holds the details, and
`examples/` holds four finished sites to learn from.

Setup once: `cd skills/model-craft && npm install && node scripts/doctor.mjs`.
